⚙️ Industrial AI Mechatronics Study Tracker

A personal, self-developed learning management system built with Streamlit to structure and track an engineering-focused study roadmap based on MIT OpenCourseWare (MIT OCW) in AI, robotics, control systems, and mechatronics.

🚀 Live Demo

👉 https://independent-mechatronics-studies-mit-hq5uncv8mpk2hdwzczgxuf.streamlit.app/

📌 Overview

This project is a personal study OS designed to help organize, track, and analyze self-paced engineering learning. It replaces manual spreadsheets with a structured web-based system for managing courses, progress, and learning reflections.

It is optimized for students following a self-directed engineering curriculum in:

Artificial Intelligence
Robotics
Mechatronics
Control Systems
Embedded Systems
Computer Vision

✨ Key Features

📚 Course Tracking
Add and manage engineering courses
Categorize by discipline (AI, Robotics, Math, etc.)
Track completion status in real time

📊 Progress Dashboard
Overall completion percentage
Category-based progress breakdown
Visual analytics for learning distribution

📝 Engineering Journal
Record study reflections and technical insights
Save ideas, concepts, and project notes

➕ Dynamic Learning Structure
Add new courses anytime
Flexible MIT OCW-based curriculum adaptation

📤 Data Export
Export progress as CSV
Use data for GitHub portfolio or LinkedIn documentation

🗄️ Persistent Storage
SQLite-based local database
Automatically saves all progress and notes

🧠 Purpose of the Project

This system is designed to support:

Structured self-learning in engineering disciplines
Long-term skill development tracking
Portfolio-building for AI / robotics / mechatronics roles
Replacement for static spreadsheets or notes

▶️ How to Run Locally
# Clone repository
git clone https://github.com/your-username/study-tracker.git

# Navigate to project folder
cd study-tracker

# Install dependencies
pip install -r requirements.txt

# Run Streamlit app
streamlit run app.py
